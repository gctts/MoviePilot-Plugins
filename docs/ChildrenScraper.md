# 儿童刮削

## 功能

- 监控儿童剧下载目录，按插件配置硬链接到目标目录。
- 可选 `TMDB`、`好学`、`PG数据库` 获取封面和简介。
- 站点和 TMDB 均失败时回退为视频截图。
- 支持源目录与目标目录双向删除联动。
- 支持多选 qB 下载器删除记录，并可刷新 MoviePilot 已配置的媒体服务器。

## 使用说明

监控方式：

- `fast`：性能模式，内部处理系统操作类型选择最优解。
- `compatibility`：兼容模式，目录同步性能降低且 NAS 不能休眠，但可以兼容 SMB 等远程共享目录。

是否重命名：

- `true`：使用自定义识别词。
- `false`：不重命名。
- `smart`：自动提取剧名。

封面比例：`2:3`

## 刮削来源

- TMDB：优先使用 TMDB 获取封面和简介。
- 好学：需在 MoviePilot 站点管理中为 `hxpt.org` 配置有效 Cookie，请求不走代理。
- PG 数据库：读取 PT Depiler 写入的元数据表，默认表名为 `public.pt_detail_meta`，并需配置数据库连接信息。

## 删除联动

- 删除源文件会同步删除硬链接。
- 删除硬链接会同步删除源文件。
- 删除整部剧目录时，会按路径匹配并删除所选 qB 下载器中的下载记录，但不删除下载文件。
