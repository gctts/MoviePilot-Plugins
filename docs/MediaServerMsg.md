# 媒体库服务器通知

## 功能

- 发送 Emby、Jellyfin、Plex 的播放、入库等通知消息。
- 同一电视剧多集同时入库时，在聚合时间窗口内合并为一条通知。
- 聚合通知可将连续集数显示为 `S01E01-E26`。
- 季集按季号、集号的数值升序显示；缺少 TMDB 信息时的简略通知也会排序并去重。
- 保留同一媒体项短时间重复投递的去重能力。

## 多集聚合说明

MoviePilot 的 Emby Webhook 解析会将电视剧事件的 `item_id` 设置为整部剧的
`SeriesId`。原插件直接使用该字段做去重，导致同一部电视剧批量入库时，第二集开始
全部被误判为重复事件，最终聚合通知只显示第一集。

本版本对电视剧入库事件优先使用 Webhook 原始 `Item.Id` 去重；缺少该字段时，回退到
`SeriesId + 季号 + 集号`。聚合分组仍使用 `SeriesId`，因此不同单集会正常进入同一条
聚合通知，而同一集的重复投递仍会被过滤。

Emby 事件可能按 `E02、E04、E01、E05、E03、E06` 的顺序到达。缺少 TMDB
信息时，简略通知会显示为 `S01E01, S01E02, S01E03, S01E04, S01E05, S01E06`；
使用连续集数合并的通知仍显示为 `S01E01-E06`。两种通知都按数字排序，
例如 `E99` 在 `E100` 前；相同集号只展示一次，多文件通知的文件数量仍按实际事件计算。

## 版本要求

- MoviePilot `>= 3.0.0`
- 插件版本：`2.1.5`
